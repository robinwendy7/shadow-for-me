# 影子 · Shadow Self / Cry for me

《饥荒联机版》纯客户端 Mod，游戏内名称为“如影随形(测试版)”。当前版本 **0.13.3**，作者：**舒晴伊子**。

## 主要功能

- **另一个自己**：按当前人物 build 显示本地影子，原版影怪黑色与半透明外观；自主跟随、停留和做动作，死亡后变成灵魂，支持本地复活演出。
- **离线对话**：结合游戏状态、近期事件、对话历史和伪记忆选择回应；内置16种MBTI对话人格，右键影子可选择。文字与对话逻辑在本地运行，不调用外部AI服务。
- **头顶说话**：影子及接管后的角色头顶显示回应；字体颜色可选红橙黄绿青蓝紫，默认红色；人物说话声音默认开启，可在Mod设置关闭。
- **授权接管**：通过对话提出任务，影子申请接管，经同意并完成覆盖演出后执行；护甲槽上方的战斗接管按钮在有待确认任务时显示“同意接管”，点击后确认该任务，接管期间显示“停止接管”。人物脚下只保留停止按钮。
- **自动战斗与走位**：内置走A及自动走位，攻击后退步使用3014原版调用与最大攻击距离限制，每一刀均核对当前攻击命中帧后再退步；支持武器/护甲选择、手杖赶路、群怪攻击检查，以及蜂后等Boss的专门处理；按Boss实际出招和虚弱状态区分走位与持续输出，侧方冲刺可抢占当前攻击或躲避。连续躲避按当前装备移速计算，确认躲避时立即切手杖；普通群战躲后重新选择最近目标。战斗接管保持到玩家主动停止。
- **料理与调味**：连续使用多个锅做饭，遍历附近可用容器获取食材，收获并存放成品；支持沃利专属料理、研磨调味粉和调味流程。
- **单人角斗场循环（本地开发版）**：对影子说“帮我循环角斗场”，同意接管后使用ASTRA经典单人协议配置、准备、开局；读取真实波次与结算状态，关间拾取补给、保留后段工具，复用内置走位战斗。可随时用停止接管按钮退出本地任务。尚未完成15关服务器通关验证。
  - **按本局掉落选装**：已有高伤害武器才淘汰弱武器，晨星单独保留；手杖、排箫、法杖和特殊护甲按用途保留。位面伤害/防御不被普通装备简单替代；读取已同步耐久和火腿棒新鲜度，背包满时允许置换升级物品，保留最后一份已识别食物，不丢弃未知玩家物品。第8关后清理船套和桨。
  - **安全空档回血**：战斗血量不高于75%且缺血至少8点时，按缺失血量、实际回血、变质和调味选择料理；不高于40%时允许短暂拉开距离寻找进食位置，最长尝试3秒、单轮不离起点8码。安全预测同时计入跑到目的地、肉食/快速进食时间和延迟；考虑全部附近怪物，包括可能在进食中解冻/醒来的近身单位。Boss机制和走位优先，当前挥刀保留至完成，不为吃东西制造空刀。身上无可用料理时，仅在安全短路径内捡取3码内回血料理，确认收到后再吃。受击、危险抢占或未开始进食时立即释放操作，迟到确认继续后台观察；回血不读写原走位的dodging/restore_dodge，等待自己的手杖确认期间不让普通攻击反向换武器。库存消耗，或观察到进食动画且经过进食时间并同步回血，才判定完成；其他来源回血不会独自充当进食确认。关间也会补血，小幅掉血时保留大回血料理。此功能只在角斗场任务中开启。
  - **关间与扫描**：休整和停止战斗前刷新24码近处怪物，新刷怪立即接回战斗；60码补给查询每0.2秒一次，每件物品每轮只评一次优先级，失效实体逐帧剔除，换关立即刷新。近处走位和战斗检查沿用原频率。
  - **帝王蟹阶段流程**：入关拾取船套，提交原版放船请求，收到真实船实体后上船，确认手持船桨后划向中央；等待本体出现再战斗，冰陆接回已有小蟹催眠和破冰逻辑，按首次破墙及本服宝石配置预留撤离时间，退到外圈等待转关。当前服务器源码对普通参与者禁止DEPLOY；需要服务器正常允许船套放置才能走完整流程，客户端不会绕过权限或伪造船。
  - **巨大蠕虫**：优先抢救地上的升级防具，利用剩余物品诱导吞食，按头部真实咀嚼动画攻击可传递伤害的土堆，地裂预警优先撤离；固定一轮诱饵落点，避免反复折返，无有效诱饵时采用普通攻击窗口。
- **钓鱼与日常任务**：支持池塘钓鱼、海钓，以及砍树、挖矿、采集、拾取、制作和移动等任务。
- **战斗音乐**：可选择接管战斗时播放内置BGM，音量跟随游戏音乐设置。

影子外观、聊天与视觉演出仅本机可见，无需服务器安装此Mod。接管真实角色时使用原版客户端操作，采集、移动、战斗等实际结果会正常同步到服务器。

## 安装与使用

1. 将仓库内容放入游戏的 `mods/Cry for me/`，确保 `modinfo.lua` 直接位于该目录中。
2. 完全重启游戏，在客户端Mod中启用“如影随形(测试版)”。无需另行启用3014、37503或自动做饭Mod。
3. 聊天输入栏按回车发送，右键拖动并记忆位置；右键影子选择MBTI人格。护甲槽上方的按钮用于战斗接管。
4. 输入“帮我砍树”“帮我做肉丸”“帮我钓鱼”等任务，并在影子申请时确认。输入“停”“停止接管”“我自己来”等，或点脚下停止按钮，交回操作。

## 当前验证状态

61组Lua 5.1离线回归通过，包含真实ASTRA请求编码、15关数据一致性、循环生命周期、动态装备取舍、原版放船请求编码、船桨确认、冰陆撤离、蠕虫窗口，以及原版料理数据和战斗回血流程检查。新增跨帧重放覆盖真实换装状态机的迟到确认、受击后交还操作、玩家与怪物同时移动、关间两次查询之间刷怪和缓存失效；这些仍是离线模拟，不是实际服务器战斗。角斗场尚未完成服务器通关测试。

角斗场兼容来源：3816458126 的 ASTRA 协议和15关数据；2067228865 交易系统不作为本地领取补给或伪造开局的入口。角斗场识别火狗地火和燃烧火焰，走位、拾取及回血避开火区；冰火狗陷阱存在时禁用鞭子，第三关怪物刷新后开场吹一次排箫并持续优先主教；临时闪避骑士/战车后恢复主教目标，不对其他单位补刀。按武器、手杖、护甲、其他补给的顺序拾取；防具入包后优先穿戴并等待装备确认，雨帽只作特殊用途衣物。旧护甲保留备用，仅满包且已有更好防具穿上时才清理；服务器确认关间休整后，按下一关必出武器提前丢弃低伤害常规武器，保留晨星和特殊工具，不以概率武器作为淘汰依据。第二、三关的冰火法杖作为猎狗陷阱，清怪后最后拾取；沉睡冰火猎狗不计作待清怪物，拾取前重新扫描确认。
