# 影子 · Shadow Self / Cry for me

《饥荒联机版》纯客户端 Mod，游戏内名称为“如影随形(测试版)”。当前版本 **0.12.23**，作者：**舒晴伊子**。

## 主要功能

- **另一个自己**：按当前人物 build 显示本地影子，原版影怪黑色与半透明外观；自主跟随、停留和做动作，死亡后变成灵魂，支持本地复活演出。
- **离线对话**：结合游戏状态、近期事件、对话历史和伪记忆选择回应；内置16种MBTI对话人格，右键影子可选择。文字与对话逻辑在本地运行，不调用外部AI服务。
- **头顶说话**：影子及接管后的角色头顶显示回应；字体颜色可选红橙黄绿青蓝紫，默认红色；人物说话声音默认开启，可在Mod设置关闭。
- **授权接管**：通过对话提出任务，影子申请接管，经同意并完成覆盖演出后执行；支持战斗接管按钮，人物脚下显示同意或停止按钮。
- **自动战斗与走位**：内置走A及自动走位，攻击后退步恢复3014原版调用与最大攻击距离限制；支持武器/护甲选择、手杖赶路、群怪攻击检查，以及蜂后等Boss的专门处理；按Boss实际出招和虚弱状态区分走位与持续输出，侧方冲刺可抢占当前攻击或躲避。战斗接管保持到玩家主动停止。
- **料理与调味**：连续使用多个锅做饭，遍历附近可用容器获取食材，收获并存放成品；支持沃利专属料理、研磨调味粉和调味流程。
- **钓鱼与日常任务**：支持池塘钓鱼、海钓，以及砍树、挖矿、采集、拾取、制作和移动等任务。
- **战斗音乐**：可选择接管战斗时播放内置BGM，音量跟随游戏音乐设置。

影子外观、聊天与视觉演出仅本机可见，无需服务器安装此Mod。接管真实角色时使用原版客户端操作，采集、移动、战斗等实际结果会正常同步到服务器。

## 安装与使用

1. 将仓库内容放入游戏的 `mods/Cry for me/`，确保 `modinfo.lua` 直接位于该目录中。
2. 完全重启游戏，在客户端Mod中启用“如影随形(测试版)”。无需另行启用3014、37503或自动做饭Mod。
3. 聊天输入栏按回车发送，右键拖动并记忆位置；右键影子选择MBTI人格。护甲槽上方的按钮用于战斗接管。
4. 输入“帮我砍树”“帮我做肉丸”“帮我钓鱼”等任务，并在影子申请时确认。输入“停”“停止接管”“我自己来”等，或点脚下停止按钮，交回操作。

## 设置

| 影子说话是否有声音 | 是 |
| 接管战斗后燃起来（BGM） | 是 |
| 自主活动范围 | 15码 |
| 主动对话间隔 | 25秒 |
| 本地复活演出 | 开启 |
